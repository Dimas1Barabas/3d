# 3D Scene

Стартовый шаблон реалистичной 3D-сцены на **Three.js** + **Vite**.

## Запуск

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Сразу увидишь демо-сцену (металлический узел
+ материал-болы), которая показывает работу PBR-материалов, мягких теней и
отражений окружения.

Управление: **ЛКМ** — вращать, **ПКМ** — двигать, **колесо** — зум.

## Как добавить свою модель

1. Скачай модель в формате **.glb** (см. `public/models/README.txt` — где брать).
2. Положи её в `public/models/scene.glb` (или поменяй `MODEL_URL` в `src/main.js`).
3. Она автоматически загрузится, отмасштабируется и встанет по центру сцены,
   заменив демо-объекты.

## Где что

- `src/main.js` — вся сцена: рендерер, свет, камера, демо-объекты, загрузчик моделей.
- `public/models/` — сюда кладутся `.glb`-файлы.
